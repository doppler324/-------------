[SERP-КОНТЕКСТ ПОИСКОВОЙ ВЫДАЧИ]
Для части ключей из первого чанка собрана реальная поисковая выдача Яндекса.
Используй эту информацию для более точной группировки по интенту:

- Ключи с ОДИНАКОВЫМИ доменами в топе выдачи → ОДИН интент (группируй вместе).
- Ключи с РАЗНОЙ выдачей → разные интенты (разделяй).
