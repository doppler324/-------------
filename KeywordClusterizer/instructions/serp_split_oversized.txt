[ЗАДАЧА: РАЗБИВКА ШИРОКОГО ИНТЕНТА]

Данная группа запросов имеет один интент (подтверждено Яндексом),
но слишком большая для одной страницы — {size} ключей, лимит {maxSize} ключей.

Это значит, что тема широкая и её нужно разбить на несколько
узких страниц с разными уточнениями.

Инструкция:
1. Разбей эту группу на логические подгруппы по {maxSize} ключей.
2. Выделяй специфичные свойства.
3. Каждая подгруппа = отдельная узкая страница со своим названием.

❗ ВАЖНО: ВЕРНИ ВСЕ КЛЮЧИ БЕЗ ПОТЕРЬ.

Формат ответа (строго JSON):
{
  "clusters": [
    {"cluster_name": "название подгруппы 1", "keywords": ["ключ1", "ключ2", ...]},
    {"cluster_name": "название подгруппы 2", "keywords": ["ключ3", "ключ4", ...]}
  ],
  "unclustered": []
}
