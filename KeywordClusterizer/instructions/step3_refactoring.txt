[ТЕКУЩАЯ ЗАДАЧА: ШАГ 3 - ФИНАЛЬНЫЙ АУДИТ СТРУКТУРЫ СТРАНИЦ]

Ниже приведена черновая кластеризация всего семантического ядра. Твоя задача — провести аудит и обеспечить, чтобы каждый кластер представлял собой одну посадочную страницу.

Критическое правило: ни один кластер не должен содержать больше {0} ключей. Это жёсткое ограничение.

Инструкция:
1. Сначала ПРОВЕРЬ, нет ли кластеров с ОДИНАКОВЫМ интентом. Если есть — ОБЪЕДИНИ их в один (не превышая лимит {0}). 
   Руководствуйся логикой: {1}.
2. Затем РАЗБЕЙ кластеры, которые всё ещё превышают {0} ключей. Каждый разбитый кластер = отдельная страница с уникальным, конкретным названием.
3. Очисти кластеры от чужеродных интентов (например, удали информационные запросы "как сделать" из коммерческих кластеров "купить/цена").
4. Кластеры, которые уже соответствуют лимиту и не дублируются — сохрани как есть.
5. ИТОГОВЫЙ РЕЗУЛЬТАТ: разумное количество кластеров, где каждый кластер содержит ключи одного интента. Не плоди лишние кластеры — сначала объединяй одинаковые интенты.
