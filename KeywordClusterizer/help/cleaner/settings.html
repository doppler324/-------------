Настройки этапа чистки

Настройки этапа чистки задаются в секции cleaner файла settings.json, расположенного в папке программы. Если секция отсутствует — используются значения по умолчанию.

{
  "cleaner": {
    "defaultModel": "deepseek-v4-pro",
    "defaultPoolSize": 1000,
    "outputCleaned": "cleaned.txt",
    "outputDiscarded": "discarded.txt",
    "outputBranded": "branded.txt",
    "outputFailed": "failed.txt",
    "instructionsInformational": "instructions/cleaner_informational.txt",
    "instructionsCommercial": "instructions/cleaner_commercial.txt",
    "instructionsBranded": "instructions/cleaner_branded.txt"
  }
}

Описание параметров

ПараметрПо умолчаниюНазначение
defaultModeldeepseek-v4-proМодель нейросети, используемая при чистке
defaultPoolSize1000Максимальное число ключей в одном пуле (запросе к AI)
outputCleanedcleaned.txtФайл с релевантными ключами
outputDiscardeddiscarded.txtФайл с отброшенными ключами
outputBrandedbranded.txtФайл с брендовыми запросами
outputFailedfailed.txtФайл с необработанными ключами
instructionsInformational—Путь к инструкции для информационных запросов
instructionsCommercial—Путь к инструкции для коммерческих запросов
instructionsBranded—Путь к инструкции по брендовым запросам

Общие настройки (используются этапом)

  • apiKey — ключ DeepSeek API.
  • deepseek.temperature / maxTokens / topP / stream — параметры генерации.
  • openrouter.apiKey — ключ OpenRouter (не требуется для стандартных моделей DeepSeek).
Примечание: при выборе модели в консоли (V4 Pro / V4 Flash) выбор переопределяет defaultModel на текущий запуск.
