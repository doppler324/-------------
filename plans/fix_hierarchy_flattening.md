# Фикс: AI переиспользует широкие теги вместо создания конкретных

## Проблема

При последовательной тегизации чанков (Фаза 3, Semantic Map-Reduce) каждый следующий чанк получает `accumulatedTagNames` от предыдущих. Промпт содержит инструкцию *"ПЕРЕИСПОЛЬЗУЙ существующие теги"*, из-за чего AI маппит уточнённые запросы в существующие широкие теги.

**Пример:** "автомобильный винтовой компрессор" → тег "винтовой компрессор" (вместо "автомобильный винтовой компрессор"). Кластер "винтовой компрессор" раздувается, теряется детализация.

## Решение

### 1. Промпт [`serp_tagging.txt`](../KeywordClusterizer/instructions/serp_tagging.txt)

Строку 8 заменить:

```diff
- - ПЕРЕИСПОЛЬЗУЙ существующие теги из списка ниже, если они подходят
+ - Создавай МАКСИМАЛЬНО КОНКРЕТНЫЙ тег для каждого запроса
+ - Если запрос УТОЧНЯЕТ общую категорию (например, "автомобильный" при общем "винтовой компрессор"), создай НОВЫЙ конкретный тег
+ - Используй существующий тег ТОЛЬКО если запрос имеет ТОЧНО ту же интенцию без уточнений
+ - Лучше создать более конкретный новый тег, чем присвоить слишком общий существующий
```

Строку с `{existing_tags}` оставить, но она будет не "переиспользуй", а "не дублируй семантику из других чанков".

### 2. Код не меняется

Логика передачи `accumulatedTagNames` остаётся — она всё ещё предотвращает дубликаты между чанками (когда AI в разных чанках создаёт "компрессор винтовой" и "винтовой компрессор"). Меняется только промпт, который инструктирует AI **не маппить** в существующий тег, если запрос уточняет категорию.

### 3. Ожидаемый эффект

| Запрос | Было (старый промпт) | Станет (новый промпт) |
|--------|---------------------|----------------------|
| винтовой компрессор | винтовой компрессор | винтовой компрессор |
| автомобильный винтовой компрессор | винтовой компрессор | автомобильный винтовой компрессор |
| промышленный винтовой компрессор | винтовой компрессор | промышленный винтовой компрессор |
| винтовой компрессор 10 бар | винтовой компрессор | винтовой компрессор 10 бар |

Кластеры станут более дробными и конкретными.
